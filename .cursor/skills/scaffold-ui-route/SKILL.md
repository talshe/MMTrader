# Scaffold UI Route

## Instructions
1. Locate the router and route list in apps/web.
2. Create a new route component following existing patterns.
3. Add any store or API hook used by the page.
4. Register the route and add navigation entry if needed.

## Checklist
- [ ] Route component created
- [ ] Store/API hook wired
- [ ] Route registered
- [ ] Navigation updated

## Example triggers
- "Add a new dashboard page"
- "Scaffold a UI route"
