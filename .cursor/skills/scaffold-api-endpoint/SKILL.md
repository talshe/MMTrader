# Scaffold API Endpoint

## Instructions
1. Locate the route folder in apps/trader and the router registration point.
2. Create a new route handler with input validation and typed response.
3. Register the route in the router.
4. Add the client method in apps/web API client and any store hook usage.
5. Add basic tests or request examples if the repo uses them.

## Checklist
- [ ] Route handler created
- [ ] Validation/schema added
- [ ] Route registered
- [ ] Client method wired
- [ ] Example or test added
